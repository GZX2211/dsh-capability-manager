### ☐ F. `meta_search` 的契约

## 三、附：目录结构草案（对应 A）

```
dsh-capability-manager/
├── package.json                 # dsh.bundle.patch + client 注入声明
├── cordis.patch.yml             # 插件行
├── tsconfig.json
├── tsdown.config.ts
├── icon.svg
├── schema/                      # （可选）配置 JSON Schema，供 Host 校验与 Client 表单
├── skills/                      # 内置 creator skill（随包分发）
│   └── <name>/SKILL.md + references/ + templates/
├── src/
│   ├── shared/                  # 两端共用契约，零运行时依赖
│   │   ├── config.ts            # 配置结构与默认值
│   │   ├── capability.ts        # 能力标识、来源、索引条目
│   │   ├── roles.ts             # 角色枚举、黑名单结构
│   │   ├── api.ts               # HTTP 端点与请求/响应形状
│   │   └── errors.ts            # 稳定错误码
│   ├── host/
│   │   ├── index.ts             # 装配与生命周期
│   │   ├── config/              # 配置读写、校验、迁移
│   │   ├── policy/              # 纯判定：池 / 初始 / 黑名单 / 可见集
│   │   ├── catalog/             # 工具与 Skill 的枚举、索引条目生成
│   │   ├── enforcement/         # 把判定落到 agent.ctx.tools.restrict
│   │   ├── roles/               # 探测 paRoles、手动绑定
│   │   ├── prompt/              # 工具索引 section（与 skill 索引合并）
│   │   ├── skill-consumer/      # shadow skill 工具 + 自建 catalog 注入
│   │   ├── search/
│   │   │   ├── index.ts         # meta_search 编排
│   │   │   ├── lexical.ts       # 正则精确召回
│   │   │   ├── semantic.ts      # 向量召回
│   │   │   ├── dedupe.ts        # 载荷级去重
│   │   │   └── embedding/       # 模型下载/校验/tokenizer/推理/缓存
│   │   ├── tools/meta_search/   # 工具定义（薄适配）
│   │   ├── builtin-skills/      # 内置 skill 的 runtime 注册
│   │   └── admin/               # Host↔Client 端点与快照
│   └── client/
│       ├── entry.ts             # 模块入口与注册
│       ├── definition.ts        # 插件展示元数据
│       ├── i18n.ts              # zh/en 词典
│       ├── style.ts             # 集中样式（无 CSS Module 管线）
│       ├── hooks/               # 快照订阅、派生状态
│       ├── lib/                 # HTTP、纯格式化
│       ├── views/               # 各管理页
│       └── components/          # 可复用控件
└── tests/
    ├── host/…                   # 镜像 src/host
    ├── shared/…
    ├── client/…                 # 镜像 src/client
    ├── integration/             # 多模块协作
    └── support/                 # 受控基础设施
```

**几个取舍说明**

| 取舍 | 理由 |
|---|---|
| `policy/` 独立于 `enforcement/` | 判定是纯函数（可测），enforcement 是副作用（碰 agent.ctx）。混在一起就无法只测判定。 |
| `shared/` 只放两端都用的形状 | 按仓库 AGENTS.md 的纯度契约：禁止运行时 import，只放类型与常量。 |
| `skills/` 在包根而非 `src/` | 它是内容资源，不是代码；且要能被 runtime 注册读取，构建时不参与打包。 |
| 不设 `src/host/tools/*` 之外的"管理工具" | 按 D-6，创建能力走 Skill，插件不需要一堆管理工具，只留 `meta_search`。 |
